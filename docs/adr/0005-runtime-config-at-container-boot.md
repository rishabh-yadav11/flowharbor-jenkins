# ADR 0005 — Runtime config is generated at container boot, not baked at build

- **Status:** Accepted
- **Context:** The UI shows the environment, version, commit and author of the running release. Baking those into the image would mean rebuilding the image per environment, which contradicts the digest-pinned promotion model in [ADR 0002](0002-immutable-ecr-digest-pinned-deploys.md) — one image, three environments.
- **Decision:** The image ships an empty `/app/public` volume and `app/entrypoint.sh` writes `runtime-config.js` at every container start, reading the environment that ECS injected (`app/entrypoint.sh:15`, `app/entrypoint.sh:52`, `app/entrypoint.sh:59`); the browser loads it as an external `<script src="/runtime-config.js">` rather than an inlined value (`app/src/app/layout.tsx:20`), and the page reads it through `useRuntimeConfig` (`app/src/lib/runtime-config.ts:89`). Every value is length-capped, `<`/`>`/U+2028/U+2029 are escaped so a hostile tag name cannot break out of the script, and URLs are restricted to `http:`/`https:` (`app/entrypoint.sh:32`, `app/entrypoint.sh:36`, `app/src/lib/runtime-config.ts:16`, `app/src/lib/runtime-config.ts:26`, `app/src/lib/runtime-config.ts:34`).
- **Consequences:** The same immutable image renders as dev, staging or prod purely from the environment it is launched in, the config file is never stored in the image or in git, and the escaping contract is a testable pure function instead of an invisible one; the cost is that the config is generated at runtime, so a boot-time write failure must be loud — it is: the generator exits non-zero on an oversize payload (`app/entrypoint.sh:51`), and the testable hook `FLOWHARBOR_SKIP_EXEC=1` lets a test run the generator without starting a server (`app/entrypoint.sh:57`).
- **Rejected alternative:** Baking the values into the image at build time, or injecting them as a server-rendered `<script>` — rejected because both make the image environment-specific, and inlining would require the browser-parsing escaping rules rather than the JSON-string ones the generator already enforces.
